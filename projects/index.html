Football match data vs bookmaker odds

Tested whether match performance data adds predictive value beyond bookmaker odds, using McNemar's test, a chronological split and 5-fold cross-validation. It did not (p = 0.579, 1.0 and 0.46). Fixed a data-loss bug from mixed date formats and removed data leakage from an early model.
